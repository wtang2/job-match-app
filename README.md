This is a React and next.js based job search application that analyzes your resume, extracts key skills and relevant experience, and matches you with suitable job opportunities.

Key features:

1. Extracts skills, experience, education, and other relevant information from your resume.

2. Calculates a job match score based on how closely your qualifications align with each job description.

3. Identifies and highlights relevant keywords and phrases shared between your resume and job postings.

4. Ranks job opportunities based on their overall relevance to your resume.

5. Displays the jobs with the strongest skill and keyword alignment first.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
